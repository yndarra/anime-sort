tools\fix_name — исправление названий папок Waifu
===============================================

names.json
    Правила переименования: "Источник": "Цель" (до 04.10 — names.txt, строки "Источник" - "Цель").
    Путь внутри Waifu без номеров; персонаж — через \\ (в JSON слэш двойной):
        "Genshin Impact\\The Tsaritsa": "Genshin Impact\\Tsaritsa"
    Если цель уже существует, папки сливаются (одинаковые файлы не дублируются).
    Новые правила вписывайте в блок "new"; regroup.py разложит их по блокам "titles".
    Правило с пустой целью пропускается (так можно оставить «на подумать»). Можно переносить персонажа в другой тайтл.
    "titles" сгруппирован по тайтлам (тайтл — из ЦЕЛИ правила): в блоке сначала переименования тайтла,
    потом его персонажей; «Other» первым, дальше по алфавиту.
    Цели — английские (официальные EN) названия; японский стиль — только где выбран вручную (Oshi no Ko).
    Прежняя версия файла после правок агента или regroup.py — names.json.bak рядом.

regroup.py
    Упорядочить names.json (перенести "new" в блоки, убрать точные повторы). --from-txt — перевести старый names.txt.

fix_name.py
    Применяет names.json к Waifu (дерево должно быть без номеров — это делают add.py и sort.py сами).
    Несколько проходов, пока что-то меняется: порядок правил не важен, цепочки A -> B -> C работают.
    Двойные пробелы в правилах приводятся к одному. --dry-run — только показать.

honkai.py
    Разносит папку «Honkai (series)» по конкретным играм (Honkai Impact 3rd / Honkai Star Rail).

dublicates.py
    Следит, чтобы имена файлов во всей Waifu были уникальными: если одно и то же имя встречается
    в нескольких папках, все копии кроме одной получают случайное 10-символьное имя
    (содержимое не сравнивается). Работает проходом при старте и затем в режиме наблюдения
    (--interval, по умолчанию раз в секунду), подхватывая новые файлы. --dry-run — только показать.
