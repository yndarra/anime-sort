tools\sort — нумерация папок Waifu
================================

sort.py
    Полный цикл: снять номера (sort_cancel) -> применить names.json (fix_name) -> пронумеровать
    каждую папку числом картинок внутри («277. Raiden Shogun»). Флаги:
      --no-edit   ничего не менять, только вывести рейтинг (так его использует ani.py);
      --json      рейтинг в JSON;
      --no-cancel / --no-fix-name — пропустить соответствующий шаг.
    Не нумеруются: «Other», «MIX», «NPC», «Other».

sort_cancel.py
    Снимает числовые префиксы «N. » со всех папок Waifu (при совпадении имён сливает папки),
    затем по умолчанию запускает fix_name. Также содержит общие функции слияния папок
    (merge_dir, remove_empty_dirs), которыми пользуются остальные скрипты.
