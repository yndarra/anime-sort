tools\add — слияние наборов в Waifu
=================================

add.py
    Читает folders.txt (по одной папке test-dataN на строку) и копирует из каждой out\0. ALL
    в Waifu. Дубликаты определяются по SHA-256 (одинаковая картинка не копируется дважды,
    разные файлы с одинаковым именем получают суффикс). Копирование атомарное (.part -> замена),
    с журналом tools\merge_journal.jsonl — после сбоя продолжает с места остановки.
    После успешного слияния набора создаёт DONE.txt в его корне; наборы с DONE.txt пропускает.
    До копирования снимает нумерацию папок (sort_cancel), после — запускает fix_name, honkai и sort.
    Флаги: --dry-run (только показать, что будет), --no-pause.

folders.txt
    Список наборов для слияния. Добавляйте только завершённые наборы
    (есть out\status_snapshot.json со status=completed и нет папки work\).
