stages — этапы конвейера
========================

Каждый тип этапа из configN.json ("type": "...") — файл с тем же именем и функцией run(ds, stage).
run.py вызывает их по порядку конфига.

wd14.py, camie.py          локальные теггеры (общий код — local.py)
ai_image.py                модель по картинке через API
json_meta.py               модель по тексту пина (metadata в файле) через API
neighbors.py               N: ближайшие определённые слева и справа — один тайтл и персонаж -> тайтл
neighbors_title.py         N-L&R: ближайшие определённые слева и справа — один тайтл -> тайтл
neighbors_left.py          тайтл соседа слева (общий код — side_neighbor.py)
neighbors_right.py         тайтл соседа справа
neighbors_lr.py            тайтл соседа слева или справа, при разных тайтлах — левого
neighbors_rl.py            тайтл соседа справа или слева, при разных тайтлах — правого
common.py                  общее: отбор файлов на этап (from / where), три раунда попыток,
                           строки лога, начало/конец этапа

Новый тип этапа: файл stages\<type>.py с run(ds, stage) и строка в STAGE_TYPES в engine\config.py.
